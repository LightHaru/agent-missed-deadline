An AI coding agent's deadpan excuse for a missed deadline, emitted as a single
UTF-8 line to `/output/entry.txt`. Dependency-free; runs on Node 22.18+.

## Run it

```sh
node main.ts            # writes /output/entry.txt
node main.ts ./out      # writes ./out/entry.txt (local use)
node --test             # smoke tests
```
